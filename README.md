## Description

This project demonstrates Flexbox and CSS Grid through five connected pages. It uses HTML and CSS, with a music theme featuring my favourite artists: GONE.Fludd, Sade, and Valyuta Skuratov.

## Pages

- **Task 0 — Navigation Bar:** A Flexbox header with the website title on the left and navigation links on the right.
- **Task 1 — Card Row:** Three equal-height artist cards with images, titles, descriptions, buttons, and hover effects.
- **Task 2 — Page Layout:** A CSS Grid layout with named areas for the header, sidebar, main content, and footer.
- **Task 3 — Image Gallery:** Nine photographs arranged in equal-sized grid cells, with captions displayed on hover.
- **Task 4 — Portfolio Page:** A combination of Flexbox and Grid, with projects on the left, personal information on the right, and a footer below.

## How to Run

1. Download or clone this repository.
2. Keep the HTML files, CSS files, and `images` folder in their original locations.
3. Open `index.html` in a browser.
4. Use the navigation bar to explore the tasks.

No installation or build tools are required.
